# 企业经营问题辅助分析

一个挂在 WorkBuddy 上的轻量化企业管理问题分析 Skill。

作者：企业管理顾问老周

## 它能做什么

企业经营者往往只能用几句话描述困扰，比如"项目越来越难拿、拿到了也不赚钱""员工流失率太大""两年没增长怎么转型"。本技能会帮你把问题一层层问清楚，最后给出一份**初步分析**：

- 从你讲的情况里，最值得注意的那一点；
- 为什么建议做一次完整诊断，以及怎么开始。

分析基于你提供的信息，信息越具体，分析越准。完整的根因判定需要一次 60 分钟访谈。

## 怎么用

1. 在 WorkBuddy 技能市场搜索"企业经营问题辅助分析"，点击安装；或直接上传本 Skill 的 ZIP 包。
2. 在对话里描述你企业的现状和遇到的问题，简要清晰即可。信息越充分，分析越准确。例如：
   - "我是一家小零部件企业老板，售后质量问题很多，怎么办？"
   - "我是做换热器的，最近员工流失率太大。"
   - "我给汽车零部件做钣金，这两年完全没有增长，怎么转型？"
3. 技能会一次问你一个问题，紧扣你的回答往下深挖，通常 5–8 问。
4. 回答结束后，技能会直接给你一份初步分析。
5. 如果你想进一步了解，回复一个「约」。这只是表达兴趣，不产生任何费用。

## 怎么联系作者

想做完整诊断时，回复「约」后选 B（预约），技能会告诉你联系方式：

> 你可以加我 QQ 1904765320，把企业情况和想解决的问题发我，我们约个 60 分钟访谈。

完整诊断 3000 元，统一价。

## 关于你的信息

- 分析只基于你告诉技能的内容，不臆造数字，不推算未提供的数据。
- 若生成问题摘要方便对接，企业名会代号化，联系方式和住址一律脱敏。
- 未经你明确同意，不会上传任何内容。

## 边界与声明

- 本技能不替代专业审计、尽调或法律意见；判断上限取决于你提供的信息质量。
- 作者资历：本人行业多年实战管理经验，曾为多家企业进行过类似咨询服务。
